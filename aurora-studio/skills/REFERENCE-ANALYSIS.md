# AurorA Studio — Reference Analysis

Use this before copying or adapting a reference.

## Output
Create a compact `reference.json` or equivalent structured note containing:
- medium / content type
- subject
- visual quality tier
- story structure
- camera behavior
- lighting
- palette roles
- typography
- materials / textures
- motion grammar
- edit rhythm
- audio / sound
- real 3D requirement
- compositing requirement
- reusable asset search terms
- technical constraints
- confidence

## Rules
1. Describe what the reference is doing, not only what it looks like.
2. Separate visual grammar from brand-specific colors/logos/text.
3. Read the current workspace product/service before proposing adaptation.
4. Never assume the same tool used by the reference is the best implementation for us.
5. Mark uncertain observations as uncertain.
6. Pass requirements to asset search and routing; do not route directly from aesthetics alone.
