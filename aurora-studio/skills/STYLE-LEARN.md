# AurorA Studio — Style Learning

Run after an approved result when the session created a genuinely reusable visual language.

## Create or update a style only when
- the look was approved or intentionally saved
- it is reusable beyond one shot
- it has clear visual/motion rules
- it is not merely a copy of someone else's branded identity

## Save
- use / avoid cases
- mood and emotional arc
- palette roles
- typography rules
- camera language
- lighting/material language
- motion and edit grammar
- audio behavior
- tool-independent requirements
- tested implementation notes per tool
- representative approved frames when allowed

Do not create a new style for every video. Prefer updating an existing style when the difference is minor.
