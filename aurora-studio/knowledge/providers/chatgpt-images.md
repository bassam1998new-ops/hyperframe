# ChatGPT Images

Last reviewed: 2026-10-05

Use when the workspace has ChatGPT browser access and an image asset is better generated/edited than built manually.

## Strong use cases
- high-quality image generation
- targeted image edits
- transparent-background assets
- visual ideation
- text inside images when that is genuinely part of the image
- cleaning/changing uploaded images

## AurorA preference
Use ChatGPT Images for:
- hero stills
- concept frames
- unusual image assets
- edits that would be slower to rebuild

Prefer HyperFrames for:
- captions
- titles
- UI
- clean charts/data cards
- typography that must stay editable

## Workflow
1. Search local/AurorA/open assets first.
2. Generate a small number of real alternatives.
3. Compare against the reference/project.
4. Keep only the selected useful asset.
5. Save the source/provider/prompt/settings when the asset is worth reusing.
