# Meta AI

Last reviewed: 2026-10-05

Use Meta AI as an optional visual-generation/editing resource.

## Strong current use cases
- image generation
- image editing
- combining multiple image references
- quick visual exploration
- clean text rendering inside generated visual compositions

Meta's current Muse Image system is the main reason to use it.

## Video
Do not treat Meta AI as AurorA's primary video-generation provider yet.

Meta has video editing/generative video features, but availability and capability are more fragmented than Flow. Use Meta video features only when the live product clearly supports the exact requested action.

## Avoid
- building a workflow that requires Meta AI
- assuming a feature is available in every country/account
- using Meta for a video task just because it is free
