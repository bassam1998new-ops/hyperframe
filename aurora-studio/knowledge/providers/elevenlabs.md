# ElevenLabs

Last reviewed: 2026-10-05

Use for voice/audio only when configured and when it materially improves the video.

## Strong use cases
- text to speech
- voice performance
- speech to text
- sound effects
- voice design
- dubbing / voice experiments

## Cost / rights
Credits and model costs are dynamic.

The current free plan includes a monthly credit allowance, but **commercial use requires a paid plan**.

Before using ElevenLabs output for a commercial/client video:
- check the user's current plan
- confirm commercial-use rights
- record the provider/model when important

## Quality workflow
- finalize script before expensive voice generation
- split long scripts into sensible segments
- preserve previous/next context for better prosody when supported
- use free regeneration only when the text/settings are unchanged
- keep final approved voice files, not every failed take
