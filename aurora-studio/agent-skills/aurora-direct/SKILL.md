# AurorA Direct mode

Read:
- `.aurora/system/skills/DIRECT.md`
- `.aurora/system/skills/PRODUCTION-GOVERNANCE.md`

Direct means fewer owner checkpoints, not lower quality.

Use:
`aurora-studio plan "<task>"`

Simple jobs may explicitly skip concept/mood.
A completed asset plan still comes before routing.
A validated per-shot build plan still comes before execution.
