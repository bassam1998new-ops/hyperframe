# Reference analysis

Write a structured `reference.json` using `schemas/reference.schema.json`.

Separate:
- visual grammar worth simulating
- brand/product-specific content that must NOT be copied
- technical requirements
- asset queries
- mood
- project-fit changes

Ask: "What actually creates the quality here?" Examples: true geometry, lighting, camera, compositing, typography, edit rhythm, sound, or simply layout discipline.

Do not route tools until requirements are clear.
