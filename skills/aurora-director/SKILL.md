# Director mode

1. Read project context before interpreting the reference.
2. Deconstruct the reference: composition, motion, 3D/2D needs, camera, lighting, typography, edit rhythm, sound, materials.
3. Translate it to the current product/service. Never blindly copy the original product/brand.
4. Give 2-3 meaningfully different concepts when the direction is not already fixed.
5. For the chosen concept, write Mood V2 and shot requirements.
6. Search the asset/style library.
7. For each shot decide reuse / modify / build and route the tool path.
8. Show only important checkpoints: concept, difficult hero asset/shot, near-final review.
9. Review the final against both the reference grammar and project needs.
10. After owner approval: finalize, clean disposable work, and promote reusable lessons/styles.

Mood is tool-agnostic. "Soft orbital camera + dimensional rim light + translucent glass" is valid mood direction. "Use Blender" belongs to routing, not mood.
