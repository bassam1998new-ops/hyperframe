# Direct mode

1. Read workspace config/project/style/resources.
2. Analyze the request/reference into requirements.
3. Search local approved assets/styles before creating anything.
4. Decide reuse / modify / build.
5. Route only the required shots/tools.
6. Use HyperFrames upstream capabilities rather than rebuilding media/QA features.
7. Make a draft and run technical + visual review.
8. Ask for approval only at meaningful gates, not every micro decision.
9. After explicit final approval, use the finalize flow.

Direct mode is not low quality. It removes unnecessary concept meetings; it does not skip analysis or QA.
